# AfriShop

## Description
AfriShop est un site vitrine qui met en valeur le savoir-faire africain à travers une sélection de produits authentiques, artisanaux et locaux.

Le site permet aux visiteurs de découvrir les produits et de contacter AfriShop.

## Fonctionnalités
- Page d'accueil
- Menu de navigation
- Présentation des produits
- Section de contact
- Affichage adapté aux téléphones et aux ordinateurs

## Technologies utilisées
- HTML5
- CSS3
- Git
- GitHub

## Structure du projet
```text
AfriShop/
├── index.html
├── style.css
├── README.md
└── images/
```

## Installation et lancement
1. Télécharger ou cloner le dépôt AfriShop.
2. Ouvrir le dossier du projet.
3. Double-cliquer sur `index.html`.
4. Le site s'ouvre dans le navigateur.
